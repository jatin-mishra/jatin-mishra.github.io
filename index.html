Open-source library · Python

Verdikt

Panel-style LLM-as-a-judge evaluation with nothing else to run. Nine judge types — pointwise, pairwise, rubric, classifier, three RAG judges and agent-trajectory — with multi-model consensus, a meta-judge that reads each member's reasoning, and multi-step pipelines with early-exit gates. Retries, model fallbacks, response caching and per-verdict cost accounting built in.

In progress · Java + Python

RAG platform: indexer + retrieval service

Two services built like production infrastructure, not a notebook. RagIndexer (Spring Boot + Temporal) runs durable indexing workflows: pull documents from S3, pluggable chunking strategies, embed, and write to both pgvector and an Elasticsearch keyword store. retrieval-service (FastAPI) does hybrid vector + keyword retrieval on bge-m3 embeddings and answers through the Anthropic SDK — with Verdikt's RAG judges as the quality gate.
